Why this session, why now

What marketing needs at Coinbase

The team tracks social sentiment across Twitter, Reddit, and news sites. Today that lives in Sprinklr — a third-party tool that doesn't connect to your internal data, can't run custom AI models, and costs a significant annual license.

Andy's team wants to know: can we bring this in-house, on the data platform we already have?

What Snowflake changes

Social data lands in S3 via Bright Data (already in procurement). From there it flows into Snowflake through Snowpipe Streaming — no ETL tool, no separate database.

Once the data is in, Cortex AI functions run sentiment, classification, and entity extraction as SQL. No Python notebooks, no external APIs.

Same data, same platform, same governance — just smarter.

Today we build a complete marketing intelligence system using synthetic data that mirrors the real pipeline.

The pieces, and what each one does

AI_SENTIMENT

Scores every social post from -1.0 (very negative) to +1.0 (very positive). Runs as a SQL function — no external API, no latency, no data leaving Snowflake.

AI_CLASSIFY

Categorizes each post into topics: regulation, DeFi, adoption, price action, security, competitor. You define the categories; the model does the rest.

AI_EXTRACT

Pulls structured entities from unstructured text: competitor names (Robinhood, Kraken, Binance), product mentions, key phrases. No regex needed.

Cortex Analyst

Natural language to SQL, grounded in a semantic view. "What's the average sentiment for Bitcoin this week?" becomes a real query your team can audit.

Cortex Search

Semantic search over your 30 campaign playbooks. "What's our response plan for a competitor launch?" retrieves the right playbook instantly.

Cortex Agent

The orchestrator. Given a question, it picks between structured data query and playbook search, then answers in business language.

AI Enrichment   Three Cortex functions, one SQL statement each

AI_SENTIMENT

Returns a float from -1.0 to +1.0 for every post. We bucket into positive (>0.2), neutral (-0.2 to 0.2), and negative (<-0.2).

SELECT
  POST_ID,
  SNOWFLAKE.CORTEX.AI_SENTIMENT(
    POST_TEXT
  ) AS SENTIMENT_SCORE
FROM SOCIAL_POSTS
LIMIT 5;

AI_CLASSIFY

Assigns each post to one of your defined topics: regulation, DeFi, adoption, price action, security, or competitor activity.

SELECT
  POST_ID,
  SNOWFLAKE.CORTEX.AI_CLASSIFY(
    POST_TEXT,
    ['regulation',
     'defi',
     'adoption',
     'price_action',
     'security',
     'competitor']
  ):'label'::STRING
FROM SOCIAL_POSTS
LIMIT 5;

AI_EXTRACT

Pulls structured entities from unstructured text. Competitor names, product mentions, key phrases — no regex, no training data.

SELECT
  POST_ID,
  SNOWFLAKE.CORTEX.AI_EXTRACT(
    POST_TEXT,
    ['competitor_name',
     'product_name',
     'key_phrase']
  ) AS ENTITIES
FROM SOCIAL_POSTS
WHERE POST_TEXT ILIKE
  '%robinhood%'
LIMIT 5;

These run live during the workshop. Pre-computed sentiment is loaded for speed, but attendees see the AI functions execute in real time.

Cortex Agent   MARKETING_SENTIMENT_AGENT

The agent is the single interface for the marketing team. It decides which tool a question needs and synthesizes the answer.

Two tools, automatic routing

Quantitative questions about sentiment scores, post volumes, KOL metrics, campaign performance, and competitor mention counts. Translates to SQL via the semantic view.

search_playbooks cortex_search
