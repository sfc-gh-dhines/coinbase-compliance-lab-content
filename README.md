# Coinbase Workshop Lab Content

Attendee-facing content for the Coinbase AI/ML workshop series, deployed as a Snowflake Workspace in each attendee's account via the DataOps.live event pipeline.

## Compliance Lab (AML Alert Triage)

| File | Description |
|------|-------------|
| `compliance_lab_walkthrough.html` | Interactive lab walkthrough with all 22 prompts. Config bar at the top to set your warehouse/database/schema. |
| `Compliance_Lab_intro_slides.html` | Facilitator intro slide deck (9 slides). Arrow keys or click to navigate. |
| `prompts.md` | Plain-text reference of the prompt cards. |
| `lab_architecture.png` | Architecture diagram (raster). |
| `lab_architecture.svg` | Architecture diagram (vector). |

## Usage

Open the walkthrough HTML for your lab from the workspace in Snowsight (Projects > Workspaces > coinbase-compliance-lab-content). Open it in a browser tab alongside Cortex Code.
