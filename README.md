# Coinbase Compliance Lab Content

Attendee-facing content for the Coinbase AML Compliance Lab, part of the Snowflake AI/ML workshop series.

## Files

| File | Description |
|------|-------------|
| `compliance_lab_walkthrough.html` | Interactive lab walkthrough with all 22 prompts. Open in a browser tab alongside Cortex Code. Has a config bar at the top to set your warehouse/database/schema. |
| `Compliance_Lab_intro_slides.html` | Facilitator intro slide deck (9 slides). Arrow keys or click to navigate. |
| `prompts.md` | Plain-text reference of the prompt cards. |
| `lab_architecture.png` | Architecture diagram (raster). |
| `lab_architecture.svg` | Architecture diagram (vector). |

## Usage

This repo is deployed as a Snowflake Workspace in each attendee's account via the DataOps.live event pipeline. Open `compliance_lab_walkthrough.html` from your workspace to get started.
