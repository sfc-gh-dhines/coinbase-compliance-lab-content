If you get stuck

      
These prompts work in any situation where CoCo hits an error or you need more clarity:


      

        
Error recovery

        

          
That failed. Here is the error: <paste it>. Explain what went wrong in one paragraph, then fix it.

          
        

      


      

        
Review before running

        

          
Before you run that, show me the SQL and tell me what it will change.

          
        

      


      

        
Plain-language explanation

        

          
I do not understand the previous step. Explain it as if I work in compliance and not in data science.
